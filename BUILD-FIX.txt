Stream Live PWA — исправление сборки Layero

1. В components/CatalogApp.tsx CircleAlert заменён на AlertCircle — доступное имя lucide-react из версии проекта.
2. Старый package-lock.json намеренно удалён: он не содержал cheerio, хотя пакет объявлен в package.json. Если обновляешь существующий GitHub-репозиторий файлами из архива, УДАЛИ старый package-lock.json и закоммить удаление, иначе Layero сначала снова попробует npm ci по устаревшему lock.
3. После удаления старого lock Layero должен выполнить npm install, затем npm run build.
4. Источники отображаются в порядке: production freedev.app, резерв domtv.blyz.ru, третье зеркало web1337.net. Карточки из разных источников не дедуплицируются.
5. Серверный загрузчик обрабатывает cookie/PoW challenge, а карточки channel.php/video.php получают embed URL для экрана просмотра. Исходная URL сохраняется для кнопки «Источник».
6. TLS fallback ограничен тремя настроенными доменами и применяется только при ошибках сертификата. Исправный сертификат на источниках всё равно предпочтительнее.
