# Stream Live PWA

Единый PWA-интерфейс для телефонов, планшетов и совместимых ТВ-устройств. Это именно PWA-проект: лендинг находится на `/`, каталог — на `/app`, экран выбранного материала — на `/app/watch/[id]`.

## Источники

- `https://domtv.blyz.ru`
- `https://streamlivetv.freedev.app`
- `https://streamliveru.web1337.net`

Каталог объединяет материалы, которые удалось получить с каждого источника. Элементы хранят исходный URL и идентификатор источника. Одинаковые материалы на разных зеркалах не удаляются: карточки каждого источника остаются отдельными. Фильтры каталога разделяют каналы, видео, форум и прочие материалы.

## Архитектура

- `app/page.tsx` — лендинг Stream Live PWA.
- `app/app/page.tsx` и `components/CatalogApp.tsx` — единая лента, поиск, фильтры источника и типа контента, избранное и диагностика источников.
- `app/api/catalog/route.ts` — собирает результаты трёх источников параллельно и возвращает карточки вместе с диагностикой каждого источника.
- `lib/scraper.ts` — серверный HTML-парсер на Cheerio. Идентификатор карточки включает источник, поэтому дубли между зеркалами сохраняются.
- `app/api/video/route.ts` — получение метаданных отдельной страницы в пределах разрешённого источника.
- `app/app/watch/[id]/page.tsx` — отдельный экран просмотра с переходом на оригинальный источник.

## Важно про доступность сайтов

Парсер не может извлечь карточки из HTML, если сайт вместо страницы каталога отдаёт проверку браузера, CAPTCHA, пустую JavaScript-оболочку или блокирует серверные запросы. В этом случае API возвращает диагностику отдельно по каждому источнику — HTTP-статус, время ответа, количество карточек и описание ошибки. Для источников, которые требуют интерактивной проверки, необходим разрешённый API или предоставленный владельцем способ серверного доступа; PWA не пытается обходить такие ограничения.

## Локальный запуск

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`. Production-сборка:

```bash
npm run build
npm start
```

Приложение должно работать на хостинге с Node.js/Next.js runtime, чтобы выполнялись маршруты `/api/catalog` и `/api/video`. Обычный статический хостинг без серверных маршрутов не сможет выполнять Cheerio-парсер.

## PWA и управление

- `public/manifest.json` задаёт режим установки PWA.
- Установку и шаги установки обслуживают компоненты `InstallButton` и `InstallSteps`.
- Элементы интерфейса поддерживают навигацию с клавиатуры и ТВ-пульта.
- Совместимость установки зависит от браузера и устройства.

## Сборка на Layero

Убедитесь, что приложение собрано в режиме Next.js server/standalone, а не статического экспорта. Команды: `npm install` и `npm run build`; старт: `npm start` (либо команда, предусмотренная конфигурацией Layero). Если меняется список зависимостей, lock-файл нужно пересоздать и закоммитить вместе с `package.json`.
