# StreamLive Native PWA

Единый интерфейс StreamLive для телефонов, планшетов и ТВ-приставок. Проект доработан на базе существующего `StreamLivePWA-main`: сохранены лендинг, установка PWA, исходные компоненты управления пультом и дизайн-система; экран `/app` теперь показывает каталог карточками вместо оболочки целого сайта.

## Что подключено

- `GET /api/catalog` — объединяет каталог собственного PHP-сайта и публичные страницы трёх источников.
- `lib/scraper.ts` — серверный HTML-парсер на Cheerio с относительными URL, lazy-load превью и несколькими универсальными наборами селекторов.
- Для основного сайта используется его существующий `api/native_home.php`, который отдаёт одобренные каналы и опубликованные видео. Каналы открываются через `embed.php?slug=...&cinema=0`, видео — через `video_embed.php?slug=...`.
- `GET /api/video` — извлекает метаданные страницы для разрешённого источника.
- `/app` — адаптивная сетка, поиск, выбор источника, избранное и нижняя навигация.
- `/app/watch/[id]` — отдельный экран просмотра, действия «Нравится», «Поделиться», PiP и переход к источнику.
- D-pad/клавиатурная навигация: яркий `:focus-visible`, увеличенная область фокуса, крупные элементы управления.

## Запуск локально

Требуется Node.js 20+.

```bash
npm install
cp .env.example .env.local # Windows: скопируйте файл вручную, если нужно
npm run dev
```

Откройте `http://localhost:3000`. Для production:

```bash
npm run build
npm start
```

## Если каталог пишет «Не удалось подключить каталог»

В сборке есть резервный режим: если `/api/catalog` не работает (например, сайт размещён на PHP/статическом хостинге без Node.js), клиент пробует получить собственные каналы и опубликованные видео напрямую через `https://streamlive.tatnet.app/api/native_home.php`. Можно задать `NEXT_PUBLIC_STREAMLIVE_SITE_URL` при сборке. Для парсинга трёх внешних доменов всё равно нужен работающий Next.js Node-сервер; браузерный fallback предназначен только для PHP-каталога StreamLive.

## Настройка собственного PHP-сайта

По умолчанию API обращается к `https://streamlive.tatnet.app`. Если адрес другой, задайте переменную окружения:

```env
STREAMLIVE_SITE_URL=https://streamlive.tatnet.app
```

Приложение не запрашивает PHP API и не требует загрузки PHP-файлов. Серверный парсер читает только три внешних сайта. Не публикуйте ключи и пароли в переменных `NEXT_PUBLIC_*`.

## Деплой

### Render (рекомендуемый вариант для Next.js + Cheerio)

- Создайте **Web Service** из репозитория.
- Runtime: Node; Build command: `npm install && npm run build`; Start command: `npm start`.
- Добавьте Никакие PHP URL или `STREAMLIVE_SITE_URL` не нужны: каталог собирается только из трёх источников.
- Убедитесь, что сервис доступен по HTTPS — это необходимо для установки PWA.

### Tatnet

Если тариф поддерживает Node.js/Next.js-сервер, используйте команды сборки и запуска выше. Если доступен только PHP/статический хостинг, Next.js API routes и серверный Cheerio-парсер не запустятся как статические файлы. Разместите Next.js-приложение на Render/другом Node-хостинге и направьте домен приложения на него. PHP-сайт не требуется.

## Ограничения источников

HTML у сторонних сайтов может меняться, а некоторые сайты запрещают серверные запросы или защищают контент от встраивания. Парсер использует универсальные селекторы и намеренно отбрасывает типичные ссылки навигации, но для стопроцентной точности каждого источника может потребоваться адаптация к его фактической разметке. Если источник блокирует iframe, приложение не может обойти это ограничение. Используйте контент, который вы вправе показывать, и соблюдайте правила источников.

## PWA и ТВ

- Android / Android TV: установите через поддерживаемый браузер.
- iPhone / iPad: Safari → «Поделиться» → «На экран Домой».
- Для телевизоров с браузерами на базе Chromium доступен PWA-режим; совместимость и установка зависят от модели и версии ОС. PWA — устанавливаемое веб-приложение, а не нативный APK, tvOS, Tizen или webOS-пакет.
